# 센터 공용 PC 로그인 · 사용 시간 관리 (Windows 10/11)

아이들이 **자기 이름과 비밀번호로 로그인**해서 정해진 시간만큼 컴퓨터를 쓰게 하는 프로그램입니다.
선생님은 **관리 컴퓨터**에서 아이 등록, 비밀번호, 시간 선물을 관리합니다.

```
 [관리 컴퓨터]  ← 선생님이 브라우저로 관리 (http://localhost:8787)
      ▲   아이 명단 · 비밀번호 · 남은 시간 저장
      │   (같은 공유기/네트워크)
 ┌────┼────────┬────────┐
[아이 PC 1] [아이 PC 2] [아이 PC 3] ...  ← 켜면 로그인 화면
```

## 이렇게 동작해요

**아이 PC**
1. 컴퓨터를 켜면 화면 전체에 **로그인 화면**이 뜹니다. 로그인 전에는 브라우저가 열리지 않습니다.
2. 아이가 **이름 + 비밀번호**를 넣으면, 관리 컴퓨터에서 그 아이의 남은 시간을 받아옵니다.
3. 오른쪽 아래에 `이름 / 남은 시간 24:59`와 **[그만하기]** 버튼이 보입니다.
   - [그만하기]를 누르면 **로그아웃(다음 친구가 쓰기)** / **로그아웃하고 컴퓨터 끄기** / 취소 중에서 고릅니다.
   - 일찍 그만하면 **남은 시간은 저장**되어 다음에 이어 쓸 수 있습니다.
   - 로그인 화면에도 **[컴퓨터 끄기]** 버튼이 있습니다.
4. 5분 전, 1분 전에 경고가 뜨고, 시간이 다 되면 30초 뒤 브라우저가 닫히고 **로그인 화면으로 돌아갑니다**.
   그러면 다음 아이가 바로 로그인할 수 있습니다.

**시간 규칙**
- 아이마다 **매주 기본 30분**. **매주 월요일 0시**에 다시 30분으로 채워집니다. (안 쓴 기본 시간은 넘어가지 않습니다)
- 선생님이 **선물 시간**을 주면 기본 시간에 더해집니다. 기본 시간을 먼저 쓰고, 다 쓰면 선물 시간을 씁니다.
- 선물 시간은 월요일에도 **사라지지 않고 남습니다**. (원하면 사라지게 바꿀 수 있음 → 아래 설정)
- 사용 중에 선물을 주면 **30초 안에** 그 아이 화면의 남은 시간이 늘어납니다.
- 한 아이가 두 컴퓨터에서 동시에 로그인할 수 없습니다.

**관리 화면 (선생님)**
- 아이 등록 / 이름 수정 / 삭제
- 비밀번호 정하기·바꾸기 (아이가 잊으면 새로 정해 주세요. 비밀번호는 안전하게 암호화돼서 저장되어 선생님도 볼 수는 없습니다)
- 🎁 시간 선물 (한 명 또는 모두에게, 메모 남기기. `-10`처럼 넣으면 시간 빼기)
- 아이별 주간 시간 따로 정하기 (예: 고학년은 주 60분)
- "이번 주 다시 채우기", 사용 중인 아이 "사용 끝내기"
- 누가 언제 어느 PC에서 얼마나 썼는지, 선물 기록

## 1단계: 관리 컴퓨터 설치 (선생님 컴퓨터 1대)

1. `server` 폴더를 관리 컴퓨터에 복사합니다.
2. `install-server.bat` 더블클릭 → "예"(관리자 권한).
3. **관리자 비밀번호**를 정합니다. (관리 화면에 들어갈 때 씀)
4. 끝나면 화면에 이런 주소가 나옵니다. **적어 두세요.**
   ```
   ■ 관리 화면 (이 컴퓨터에서):   http://localhost:8787
   ■ 아이 PC의 config.json 에 넣을 ServerUrl:
       http://192.168.0.10:8787
   ```
5. 브라우저에서 `http://localhost:8787`을 열고 관리자 비밀번호로 들어가 **아이들을 등록**합니다.

> - 관리 컴퓨터는 아이들이 PC를 쓰는 동안 **켜져 있어야** 합니다. (켜지면 서버는 자동 실행돼요. 로그인 안 해도 됩니다)
> - 같은 네트워크의 다른 컴퓨터나 **휴대폰**에서도 `http://192.168.0.10:8787`로 관리 화면을 열 수 있습니다.
> - 공유기 설정에서 관리 컴퓨터의 **IP를 고정**해 두면 주소가 바뀌지 않아 좋습니다.

## 2단계: 아이 PC 설치 (아이 PC마다)

1. **아이용 Windows 계정**을 하나 만듭니다. (예: `학생`) → 계정 유형은 **표준 사용자**.
   - 컴퓨터를 켜면 이 계정으로 바로 들어가게 하려면: `Win+R` → `netplwiz` → "사용자 이름과 암호를 입력해야..." 체크 해제.
2. `client` 폴더를 아이 PC에 복사하고 `config.json`을 메모장으로 엽니다.
   - `ServerUrl`: 1단계에서 적어 둔 주소 (예: `http://192.168.0.10:8787`)
   - `CenterName`: 로그인 화면에 보일 센터 이름
   - `ExemptUsers`: **선생님 Windows 계정 이름**을 꼭 넣으세요. (이 계정은 로그인 화면이 안 뜸)
3. `install.bat` 더블클릭 → "예". (관리 컴퓨터에 연결되는지 먼저 확인합니다)
4. 재부팅하면 로그인 화면이 뜹니다.

> **설치 전 시험:** 아이 PC에서 `test.bat`을 실행하면 로그인 화면이 **일반 창**으로 떠서 시험해 볼 수 있습니다. (브라우저를 닫거나 작업 관리자를 막지 않음)

## 설정

### 아이 PC (`client/config.json`)
| 항목 | 기본값 | 설명 |
|---|---|---|
| `ServerUrl` | | 관리 컴퓨터 주소 |
| `CenterName` | | 로그인 화면의 센터 이름 |
| `LogoFile` | `"logo.png"` | 로그인 화면 로고. 다른 로고로 바꾸려면 `client` 폴더의 `logo.png`를 같은 이름으로 덮어쓰기 |
| `ShowShutdownButton` | `true` | 로그인 화면에 [컴퓨터 끄기] 버튼 표시 |
| `EndAction` | `"Lock"` | 시간이 끝나거나 그만하면: `Lock` 로그인 화면으로 / `Logoff` Windows 로그아웃 / `Shutdown` 컴퓨터 끄기 |
| `WarnMinutes` | `[5, 1]` | 경고할 남은 시간(분) |
| `GraceSeconds` | `30` | 시간이 끝난 뒤 저장할 시간(초) |
| `ExemptUsers` | | 로그인 화면이 안 뜨는 선생님 Windows 계정 |
| `DisableTaskManager` | `true` | 아이 계정에서 작업 관리자를 막아 로그인 화면을 못 끄게 함 |
| `Browsers` | 크롬·엣지·웨일 등 | 로그인 전에 막고, 끝나면 닫을 프로그램 |

바꾼 뒤 `install.bat`을 다시 실행하세요.

### 관리 컴퓨터
- **기본 주간 시간(30분)** 과 **관리자 비밀번호**: 관리 화면의 **[설정]** 버튼.
- **선물 시간도 월요일에 사라지게** 하려면: `server/server-config.json`의 `"BonusResetsWeekly"`를 `true`로 바꾸고 `install-server.bat` 다시 실행.
- **관리자 비밀번호를 잊었을 때**: 관리 컴퓨터에서 `reset-admin-password.bat` 실행.

## 알아 두세요

- **관리 컴퓨터가 꺼져 있거나 네트워크가 끊기면 아이들이 새로 로그인할 수 없습니다.** 이미 쓰고 있던 아이는 남은 시간까지 계속 쓰고, 연결되면 다시 맞춰집니다.
- 아이가 쓰다가 컴퓨터를 **재부팅하면** 그때까지 쓴 시간만 빠지고, 다시 로그인하면 남은 시간으로 이어서 씁니다.
- 프로그램이 강제로 꺼져도 1분 안에 다시 켜지고 로그인 상태도 그대로 이어집니다.
- 아이용 Windows 계정은 꼭 **표준 사용자**로 두세요. 관리자 계정이면 프로그램을 지울 수 있습니다.
- 데이터(아이 명단, 시간, 기록)는 관리 컴퓨터의 `C:\ProgramData\PCTimerServer\data.json`에 있고, 매일 `backup` 폴더에 자동 백업됩니다(60일치).
- 기록 파일: 관리 컴퓨터 `C:\ProgramData\PCTimerServer\server.log`, 아이 PC `C:\ProgramData\PCTimer\log.txt`.
- 같은 센터 네트워크 안에서만 쓰도록 만들었습니다. 인터넷 밖에서 관리 화면에 접속하도록 공유기 포트를 열지는 마세요.

## 제거
- 아이 PC: `client/uninstall.bat` (작업 관리자 막기도 풀립니다)
- 관리 컴퓨터: `server/uninstall-server.bat` (데이터를 지울지 물어봅니다)

## 파일 구성
```
server/  (관리 컴퓨터)
  server.ps1              관리 서버
  admin.html              관리 화면
  server-config.json      포트 등 설정
  install-server.bat      설치
  uninstall-server.bat    제거
  reset-admin-password.bat 관리자 비밀번호 다시 정하기
client/  (아이 PC)
  client.ps1              로그인 화면 + 시간 제한
  launch.vbs              검은 창 없이 실행
  config.json             설정
  logo.png                로그인 화면 로고
  install.bat / uninstall.bat / test.bat
```
