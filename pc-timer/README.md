# 공용 PC 30분 사용 시간 제한 (Windows 10/11)

센터 공용 컴퓨터에서 **컴퓨터를 켜고 브라우저를 처음 연 순간부터 30분**이 지나면 자동으로 컴퓨터를 끕니다.

## 동작 방식

1. 아이가 로그인하면 타이머가 화면에 보이지 않게 대기합니다.
2. 브라우저(크롬, 엣지, 웨일, 파이어폭스 등) **창이 처음 열리는 순간** 시간 측정을 시작합니다.
   - 오른쪽 아래에 `남은 시간 29:59`가 표시됩니다. (누르면 위/아래로 자리를 옮깁니다)
   - 브라우저를 닫았다가 다시 열어도 시간은 **계속 흐릅니다**.
3. **5분 전, 1분 전**에 화면 가운데에 경고 창을 띄웁니다.
4. 30분이 되면 "사용 시간이 끝났어요" 안내를 띄우고 **30초 뒤 컴퓨터를 끕니다**. (저장할 시간)

아이가 작업 관리자로 타이머를 강제로 꺼도, 1분 안에 **남은 시간 그대로** 다시 켜집니다.

## 설치

1. 이 `pc-timer` 폴더를 각 컴퓨터에 복사합니다. (USB 등)
2. 필요하면 `config.json`을 메모장으로 열어 설정을 바꿉니다. (아래 표 참고)
   - **`ExemptUsers`에 선생님 Windows 계정 이름을 꼭 넣어 주세요.** 안 넣으면 선생님 계정도 30분 뒤 꺼집니다.
3. `install.bat`을 더블클릭 → "예"(관리자 권한) 누르기.
4. 로그아웃 후 다시 로그인하거나 재부팅하면 적용됩니다.

설정을 바꾸려면 `config.json`을 고친 뒤 `install.bat`을 다시 실행하면 됩니다.

## 설치 전에 시험해 보기

`test.bat`을 더블클릭한 뒤 브라우저를 여세요. **2분 제한**으로 돌아가고, 끝나면 컴퓨터를 끄지 않고 **브라우저만 닫습니다**. 창을 닫으려면 작업 관리자에서 `Windows PowerShell`을 종료하세요.

## 설정 (`config.json`)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `LimitMinutes` | `30` | 브라우저를 처음 연 순간부터 쓸 수 있는 시간(분) |
| `WarnMinutes` | `[5, 1]` | 남은 시간이 몇 분일 때 경고할지 |
| `EndAction` | `"Shutdown"` | `Shutdown`: 컴퓨터 끄기 / `Logoff`: 로그아웃 / `CloseBrowser`: 브라우저만 닫고 다시 못 열게 함 |
| `GraceSeconds` | `30` | "시간 끝" 안내 후 실제로 끄기까지 기다리는 시간(초) |
| `CooldownMinutes` | `0` (끔) | 예: `10` → 시간이 끝난 뒤 10분 동안 다시 못 씀. 쓰다가 몰래 재부팅해도 10분 안에 켜면 **남은 시간이 이어짐** |
| `ExemptUsers` | `["선생님", "Administrator"]` | 시간 제한을 받지 않는 Windows 계정 이름 |
| `Browsers` | 크롬/엣지/웨일 등 | 감시할 브라우저 프로그램 이름 (`.exe` 빼고) |

> **재부팅 꼼수 막기:** 기본 설정(`CooldownMinutes: 0`)에서는 아이가 시간이 끝나기 전에 재부팅하면 다시 30분이 주어집니다. 이게 걱정되면 `CooldownMinutes`를 `10` 정도로 두세요. 다만 이 경우 다음 아이도 10분 동안 그 컴퓨터를 못 쓰게 됩니다.

## 꼭 같이 해 두면 좋은 것

- **아이들 계정은 "표준 사용자"로** 만들어 주세요. 관리자 계정이면 아이가 타이머 자체를 지울 수 있습니다.
  (설정 → 계정 → 가족 및 다른 사용자 → 계정 유형 변경)
- 시간 제한은 **브라우저 기준**입니다. 게임 등 다른 프로그램만 쓰면 타이머가 시작되지 않습니다. 다른 프로그램도 넣고 싶으면 `Browsers`에 그 프로그램 이름을 추가하세요.
- 기록은 `C:\ProgramData\PCTimer\log.txt`에 남습니다. (언제 시작/종료됐는지)

## 제거

`uninstall.bat`을 더블클릭 → "예".

## 파일 구성

| 파일 | 역할 |
|---|---|
| `timer.ps1` | 타이머 본체 (설치 시 `C:\Program Files\PCTimer`로 복사) |
| `launch.vbs` | 검은 창 없이 타이머 실행 |
| `config.json` | 설정 |
| `install.bat` / `install.ps1` | 설치 (로그인 시 자동 실행 + 1분마다 감시 작업 등록) |
| `uninstall.bat` / `uninstall.ps1` | 제거 |
| `test.bat` | 2분짜리 시험 실행 |
